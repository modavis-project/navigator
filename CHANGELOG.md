# Changelog

## 1.0.0 — 2026-09-09

First standalone Navigator software release, accompanying POD 1.6.0.

Includes the public organ, actor, place, event and virtual-instrument views;
source-qualified specifications; maps; JSON and semantic evidence delivery;
vocabulary and OMARO browsing; terminology searches and related-organ filters;
research comparisons and builder networks; and contextual page FAQs.

The distribution adds a portable Docker Compose setup, verified input manifests,
locked application dependencies, separate read-only runtime access, a pinned
resources attachment and reproduction checks. It does not modify POD 1.6.0 or
assign a new dataset release.
