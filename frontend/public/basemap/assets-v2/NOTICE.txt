Navigator basemap

The map style adapts OpenFreeMap Positron. Street-level detail is requested
from OpenFreeMap only when the visible map uses it.
Source: https://tiles.openfreemap.org/styles/positron
Unmodified style snapshot SHA-256:
40565c7a5a0961cb1b33afefb55c1e48f06575d2e45868b309582334eeab82f1
Project: https://github.com/hyperknot/openfreemap-styles
Street detail: https://www.openstreetmap.org/copyright
Tile schema: https://openmaptiles.org/

The overview combines these public-domain Natural Earth 5.1.2 datasets:
- ne_50m_land
- ne_50m_lakes
- ne_50m_admin_0_boundary_lines_land
- ne_50m_admin_0_countries
- ne_10m_populated_places_simple
Source: https://github.com/nvkelso/natural-earth-vector/tree/v5.1.2/geojson
Terms: https://www.naturalearthdata.com/about/terms-of-use/
Boundary policy: https://www.naturalearthdata.com/about/disputed-boundaries-policy/
The data is prepared by scripts/build_basemap_geography.py.

The overview uses selected glyph ranges from OpenFreeMap's Noto Sans
Regular and Bold stacks. The font directories under
/basemap/openfreemap/v2/fonts/ include the Noto copyright notices and
the SIL Open Font License 1.1.
Source archive: https://assets.openfreemap.com/fonts/ofm.tar.gz
MapLibre glyphs: https://github.com/maplibre/demotiles/tree/c071b1914cb6f0ee8a8014d51a906ddfd7149848/font
OpenMapTiles font sources: https://github.com/openmaptiles/fonts/tree/master/noto-sans
