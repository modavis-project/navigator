# Contributing

Report a reproducible problem with the Navigator version, POD version, affected
route, expected behavior and actual result. Do not attach credentials, private
source material or personal browser state.

For changes, run the unit tests, frontend tests and build in
`docs/DEVELOPMENT.md`. Changes to public data presentation should also be checked
against a populated dataset in desktop and narrow browser views. Keep source
wording, attribution, unresolved identities and configuration uncertainty intact.
